# Chamber review full texts

The [PDF index](index.csv) records each retained original with its citation, DOI or report number, source URL, redistribution basis, page count and SHA-256 checksum. Use the DOI or report number to match a PDF to the publication register.

- [Journal articles](journal-articles/) contains publisher PDFs filed by issue year and first author.
- [Technical reports](technical-reports/) contains agency PDFs filed by year, first author or editor, and accession number.

Each archived PDF retains its source license and notices. The repository software license applies to the software. Copies with reuse limits remain subject to the terms in the index and in the original publication.
